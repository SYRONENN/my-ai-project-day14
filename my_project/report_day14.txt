Задание 21 Итоговая проверка чата
1. Продолжение разговора: минимум четыре пользовательских сообщения за один запуск. Хотя бы два уточнения зависят от предыдущих ответов. - да
2. Ограничение: пользователь задаёт условие и затем уточняет задачу. Пока условие есть в передаваемой истории, проверьте, учитывает ли его помощник. - да
3. Пустой ввод и одни пробелы: сообщений в истории не прибавляется, запрос к API не выполняется. - да
4. Команда «история»: роли показаны, список не изменён, запрос к API не выполняется. - да
5. Команда «очистить»: остаётся один system, следующий обычный обмен увеличивает длину до трёх. - да
6. Лимит после четырёх полных обменов: остаётся system и три последние пары. Проверьте это на демонстрационных сообщениях с различимым текстом. - да
7. Команда «ВЫХОД» с пробелами: программа завершается без отправки команды модели. - да
